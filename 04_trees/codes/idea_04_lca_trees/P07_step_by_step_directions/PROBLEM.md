# Step-By-Step Directions From A Binary Tree Node To Another (LeetCode 2096)

## Problem Statement
Given the root of a binary tree with unique values and two node values `startValue` and `destValue`, find the shortest path from `startValue` to `destValue`. Represent the path as a string of step directions:
- `'U'`: move from a node to its parent node.
- `'L'`: move from a node to its left child.
- `'R'`: move from a node to its right child.
